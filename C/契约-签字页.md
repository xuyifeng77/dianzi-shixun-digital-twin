## 契约 1 · 串口帧协议 ASCII **v1.1**

**物理层**：UNO D0/D1 ──USB──> Duo USB-A，115200 8N1，ASCII 行，`\n` 结尾，无校验。
设备名**两端自动探测**：正品 UNO = `/dev/ttyACM0`，CH340 克隆板 = `/dev/ttyUSB0`（实测本机为 CH340，Windows 侧 COM7）。

### 上行（UNO → Duo）

| 帧 | 格式 | 频率 |
|---|---|---|
| 环境 | `@E,t,h,smoke,flame,light,sound,rst` | 2000 ms + 收到 `@Q` 立即 |
| 门磁 | `@D,0\|1` | 状态变化（40 ms 去抖后） |
| 计数 | `@C,<n>` | 每次遮挡沿，n 累计 |
| 刷卡 | `@R,<UID 8 位十六进制>` | 每次读卡 |
| 报警 | `@A,<0\|1\|2>,<NONE\|SMOKE\|FLAME\|TEMP>` | **等级变化时**才发 |

字段单位：`t` ℃（1 位小数）、`h` %RH（1 位小数）、`smoke/flame/light/sound` = PCF8591 原始值 0–255、`rst` = MCUSR 0–15。

### 下行（Duo → UNO）

| 帧 | 合法范围 | 非法时 |
|---|---|---|
| `@L,<ms>` | **500 ≤ ms ≤ 10000** | 只响拒绝音，**舵机与继电器不动** |
| `@Q` / `@Z` / `@M,<0\|1>` | — | 未知命令静默忽略 |

### 冻结的三条硬规矩

1. **坏帧必须拒绝，不许"钳位救场"**——v1.1 的 `min(ms,10000)` 会把 `@L,-1` 变成一次 10 s 开锁，方向是反的。
2. **链路丢失不改变继电器状态**（本地判定独立于链路）。
3. 超时口径：Duo 心跳 10 s、桥接判死 35 s、固件 `LINK LOST` 15 s。

### 为什么留 ASCII 不留 `02 §4.2` 的二进制帧

现场可读、`cat` 串口就能看、抓包不用解二进制。**代价：无 CRC**，靠 20 cm 板内 TTL + 变化上报 + 字段范围校验压误码——写进报告风险表认账。三套协议并存的现状就此结题。

### 验收证据（真机，2026-11-23）

- 编译：Flash 23362 B (72%)、SRAM 1302 B (63%)
- `@E` 2 s 一帧，8 字段，rst=0 正常上电
- 门磁一次动作**只发一条** `@D`
- `@L` / `@L,-1` / `@L,99999` / `@L,0` → 两声拒绝音；`@L,3000` → 静默开锁

## 契约 2 · 接线表 **v1.0**

一句话：**17 个 GPIO 已用（D2–D13、A0–A2、A4/A5），A3 空闲；D0/D1 为串口专用。**

| 关键分配 | 值 |
|---|---|
| D2 / D3 | DHT11 / DS18B20（单总线） |
| D4 / D5 / D6 | 有源蜂鸣器 / 7 色 LED（PWM） / 继电器（**低电平吸合**） |
| D7 / D8 / D9 | 舵机（独占 Timer1） / IR 接收 VS1838B / 风扇（仅 digitalWrite） |
| D10–D13 | RC522（SPI，3.3 V） |
| A0 / A1 / A2 / A3 | 光电 / 干簧管（闭合=LOW）/ 触摸 / **空闲** |
| A4 / A5 | I2C：PCF8591(0x48) + LCD(0x27) + OLED(0x3C) |

**电源分域**：5V 逻辑（Duo USB-A，峰值 ≤450 mA 且 ≥4.75 V）｜独立 5V（舵机 + 风扇，**禁止从 UNO 取电**）｜3.3V 射频（RC522）。

**四处必须做的小电路**：继电器 IN 加 10 kΩ 上拉（防复位误导通）｜风扇 S8050+1N4007+1 kΩ｜RC522 的 BSS138 电平转换｜DS18B20 4.7 kΩ 上拉。

**冲突清单**：D9/D10 无 `analogWrite`（Timer1 被舵机占）｜D13 不能开 IR 反馈 LED｜A4/A5 不可再接 I2C 从机｜单脚 7 色灯只改亮度、不能选色。

### 与旧文档的差异（以本表为准）

| 项 | 旧值 | 新值 |
|---|---|---|
| 引脚计数 | "16/16 已满" | 17 个 GPIO，A3 空闲 |
| A3 | 无源蜂鸣器 | 空闲 |
| D9 | 风扇 PWM | 仅 `digitalWrite` |
| 授权判断 | PC 侧比对 | Duo 侧 `CARDS` 白名单 |
| 电路图 | 缺 D8 | 已补 VS1838B |

## 变更规则

1. 改字段/引脚 = 版本 +0.1 + A 重新签字 + 同一天改固件、桥接、看板三处。
2. 只改注释/措辞 = 不改版本，在变更记录里记一行。
3. 任何一方发现"代码与契约不符"，**以契约优先**，改代码不改契约（除非按第 1 条走流程）。
