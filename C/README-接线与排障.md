# 标准版 · 单节点物联网终端 · 接线与排障

> 本版为**原方案**（含三极管驱动、电平转换、打孔固定）；此前的"零焊接简化版"已撤回。
> 架构：Duo 提供语义（视觉计数）＋ UNO 提供物理事实（传感 / 门禁 / 联锁），两者走 USB 串口。

## 1 接线表

| 模块 | 引脚 → UNO | 说明 |
|---|---|---|
| DHT11 模块 | DATA→D2 | 模块自带 10kΩ 上拉 |
| DS18B20 模块 | DQ→D3 | 模块自带 4.7kΩ；裸件需外加 |
| **有源**蜂鸣器（必须） | I/O→D4 | 节奏编码报警；无源模块不适用（需方波，`tone()` 与 IRremote 冲突） |
| 7 色 LED 模块 | S→D5 | 状态色 |
| 继电器模块 | IN→D6 | **低电平吸合**；上电即吸合给负载供电 |
| 舵机 SG90 | 橙→D7 | 红/棕接**独立 5V**，禁止从 UNO 5V 取电 |
| IR 接收头 | OUT→D8 | IRremote ≥4.0 |
| 风扇 | 控制→D9 | **经 NPN/MOS 驱动**，风扇电源独立 5V，加续流二极管 |
| RC522 | SDA→D10 SCK→D13 MOSI→D11 MISO→D12 RST→3.3V GND | **3.3V 供电**，信号经 BSS138 四路电平转换 |
| U 型光电 | OUT→A0 | 计数 / 到位，调电位器 |
| 干簧管 | OUT→A1 | 门磁 |
| 触摸模块 | OUT→A2 | 手动确认 |
| PCF8591 | SDA→A4 SCL→A5 | 地址 0x48，四路模拟挂 AIN0~3 |
| LCD1602 (I2C) | SDA→A4 SCL→A5 | 地址 0x27 或 0x3F |
| OLED 128×64 | SDA→A4 SCL→A5 | 地址 0x3C，U8X8 文本模式 |
| UNO | USB → Duo IO 底板 USB-A | Duo 侧识别为 `/dev/ttyUSB0` |

> 备用链路：IO 底板四针 3V3/RX/TX/GND，UNO TX→Duo RX 须 **1k/2k 分压**。
> I2C 总线上三个从机地址不冲突，可并联；A4/A5 各加 4.7kΩ 上拉到 5V（模块多数已带）。

## 2 三条关键电路

1. **继电器取反逻辑**：线圈常吸合＝给台面负载持续供电；烟雾/火焰达 L2 时释放触点断电。**UNO 自身供电不得串在触点回路**，否则报警即自锁。
2. **风扇驱动**：D9 只能 `digitalWrite`（Servo 库独占 Timer1，D9/D10 的 `analogWrite` 失效）。基极串 1kΩ，风扇两端反并 1N4148/1N4007 续流。
3. **舵机独立供电**：堵转 1A，与 UNO 共地但电源分开；否则刷卡瞬间 UNO 复位。

## 3 装配顺序

1. 亚克力底板打孔，螺柱固定 UNO 与面包板。
2. 焊接/搭三处小电路：风扇驱动（三极管＋基极电阻＋续流管）、RC522 电平转换（BSS138×4）、DS18B20 上拉（若为裸件）。
3. 按接线表插传感器与显示（DHT11、DS18B20、PCF8591、光电、干簧管、触摸、LCD、OLED、RC522）。
4. 接执行器：蜂鸣器、7 色 LED、继电器、风扇、舵机。
5. 上电自检：先不接舵机与风扇，确认 LCD 有数、`@E` 每 2s 一帧。
6. 接独立 5V 负载，确认共地。

## 4 排障清单

| # | 现象 | 原因 | 处理 |
|---|---|---|---|
| 1 | 桥接读不到任何行 | 设备名 / 波特率错 | `lsusb`、`ls /dev/ttyUSB*`；确认 115200 |
| 2 | 数据跳变 | 杜邦线松动 / 过长 | 插紧，线长 ≤20cm |
| 3 | 编译报 `IRremote.h` 不存在 | 版本 <4.0 | 升 4.x，改 `#include <IRremote.hpp>` + `IrReceiver.begin()` |
| 4 | `lcd` 无 `init()` 成员 | 装成另一家 LiquidCrystal_I2C | 只留 Frank de Brabander 1.1.4 |
| 5 | DS18B20 恒 −127 | 裸件无上拉 | 补 4.7kΩ 到 5V |
| 6 | 湿度 `nan` | 读取间隔 <1s | 采样保持 ≥1s |
| 7 | PCF8591 恒 0/255 | 地址或控制字错 | `i2cdetect -y 1` 见 0x48；控制字 `0x40\|ch` |
| 8 | LCD 花屏 | 地址 0x27 vs 0x3F | 换地址重试 |
| 9 | OLED 全黑 | 用了 SW_I2C 构造 | 必须 `U8X8_SSD1306_128X64_NONAME_HW_I2C` |
| 10 | RC522 不读卡 | 供电非 3.3V / 电平转换错 | 先量 VCC=3.3V，再查 SCK/MOSI/MISO 对丝印 |
| 11 | 刷卡即复位 | 舵机从 UNO 5V 取电 | 改独立电源，保持共地 |
| 12 | 风扇不转 | 驱动管方向/基极电阻错 | 万用表量 D9 高电平时集电极是否拉低 |
| 13 | 报警后风扇常转 | `lv>=1` 判据写反 | 注意级才通风，危险级断电 |
| 14 | 刷卡无反应 | Duo 未回 `@L` | 确认收到 `@R,` 且帧尾为 `\n` |
| 15 | 光电计数乱加 | 无消抖 | 加 50ms 消抖或调模块电位器 |
| 16 | MQ-2 上电就报警 | 预热期未屏蔽 | 上电等 30s（代码 `WARMUP_MS` 已处理） |
| 17 | 蜂鸣器接上完全不响 | 装成了**无源**模块（需 2–5 kHz 方波），或模块是低电平触发 | 跑 `buzzer_check.ino` 判定；无源则换套件第 19 项有源模块；低电平触发则代码电取反 |

## 5 验收

- [ ] 桥接每 2s 收到 `@E,温度,湿度,烟雾,火焰,光照,声音`
- [ ] 打火机放气 → 3s 内 `@A,2,SMOKE`：风扇转、长鸣、红灯、台面负载断电
- [ ] 有效卡 → `@L,3000` → 舵机开锁 3s 回锁；非法卡两声短鸣
- [ ] 软串口 / USB 链路断开时 LCD 显示 `LINK LOST`，重连自动恢复
- [ ] 单节点计数标定 **120 人次**（12 组 × 10 人次），误计 ≤2%
