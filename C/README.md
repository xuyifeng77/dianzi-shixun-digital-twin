## 三、开工顺序（今天下午 3 小时）

1. UNO 插电脑，Arduino IDE 打开 [`UNO_Node/UNO_Node.ino`](UNO_Node/UNO_Node.ino)，**编译一次**，记 Flash/SRAM 占用（SRAM > 70% 要警惕）。
2. 串口监视器确认能出 `@E,...`；先确认串口名是 `COMx` 还是 `/dev/ttyACM0`。
3. 按 [`10-C岗-硬件执行层.md`](10-C岗-硬件执行层.md) §四的引脚表核对实物跳线，把不一致项写进接线表。
4. 命令行编译：`arduino-cli compile --fqbn arduino:avr:uno ".\C\UNO_Node"`（在仓库根目录执行）。
