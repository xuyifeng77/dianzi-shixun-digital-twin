# 电子实训 · 「四目边缘」实验室数字孪生

电子实训课程的创新选题与系统设计工作区：以 **2 × Milk-V Duo 256M（SG2002 / 256MB）** 起步（可扩至 4 块）构成边缘视觉集群，以 **Arduino IOT 学习套件 A 盘（C 套餐 51 项）** 的 Uno 作为硬实时执行层与第二感知通道，用实测数据论证"推理放在边缘还是中心"。

> 名字里的"四目"是目标形态（4 节点分区覆盖）；**当前持有 2 套**，节点 A/B 在用、C/D 为扩展位。
