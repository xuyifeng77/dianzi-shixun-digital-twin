# 电子实训 · 「四目边缘」实验室数字孪生

电子实训课程的创新选题与系统设计工作区：以 **2 × Milk-V Duo 256M（SG2002 / 256MB）** 起步（可扩至 4 块）构成边缘视觉集群，以 **Arduino IOT 学习套件 A 盘（C 套餐 51 项）** 的 Uno 作为硬实时执行层与第二感知通道，用实测数据论证"推理放在边缘还是中心"。

> 名字里的"四目"是目标形态（4 节点分区覆盖）；**当前持有 2 套**，节点 A/B 在用、C/D 为扩展位。

## 硬件清单概览

| 板块 | 关键模块 | 用途 | 数量 |
|---|---|---|---|
| 边缘平台 | **Milk-V Duo 256M**（SG2002：C906@1GHz + C906@700MHz + 8051、**256MB DDR3**、**NPU 1 TOPS INT8**） | 各带摄像头本地 NPU 推理，只上传元数据 | **2**（可扩 4） |
| 边缘平台 | Duo USB&Ethernet IO 底板（`DUO_IOB_V1.11`） | 网口接入路由器、独立供电；**插上后 USB-NCM 失效** | **2**（可扩 4） |
| 边缘平台 | CAM-GC2083 摄像头模组（200 万像素、1080p@30fps） | 区域视觉采集 | **2**（可扩 4） |
| 边缘平台 | TF 卡 32GB ×2（**已烧录系统**）、5V/2A 电源 ×2、网线 ×3、**带 DHCP 的路由器 ×1**、CH340 串口线 ×1、PC ×1 | 组网、供电与协调层 | 卡已有，其余**待购（约 ¥20）** |
| Arduino 侧 | Uno（ATmega328P，仅 1 个硬件串口） | 硬实时执行层 + 第二感知通道 | 1 |
| 感知 | MQ-2 烟雾、火焰、光敏、声音（经 PCF8591 走 I2C）、DHT11、DS18B20、BMP180 | 环境与安全感知、MQ-2 温湿度补偿 | 各 1 |
| 门禁 ★ | RFID RC522、U 型光电、干簧管 + 磁铁、舵机、触摸开关、HC-SR04 | 三源协同防尾随与出入计数（光电提供独立真值） | 各 1 |
| 执行 | 继电器（SIL-1 断电）、风扇套件组、有源 + 无源蜂鸣器、7 色 LED | 断电、通风、分级报警 | 各 1 |
| 显示交互 | IIC LCD1602、OLED、IR 接收 + 红外遥控器 | 区域状态、事件日志、答辩现场控制 | 各 1 |
| 数据 | PCF8591（4 路 ADC 扩展，`0x48`）、DS1302（本地时间戳） | 腾出 A0–A3 当数字口、断点续传 | 各 1 |

套件使用率：**核心 31 项 / 可选备用 10 项 / 明确不使用 10 项**。明确不接：激光、TCS3200 颜色、红外循迹、红外避障、双色 LED、电位器（回答不了本项目的系统级问题）；WIFI 模块的配套资料不在光盘内，本项目不使用。
