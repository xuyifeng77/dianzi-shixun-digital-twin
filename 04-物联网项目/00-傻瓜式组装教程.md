# 傻瓜式组装教程 · 从零到能跑（单节点物联网终端）

> 面向第一次上手的同学。**每一步都有"怎么做 / 你应该看到什么 / 卡住了怎么办"**。
> 全程只需：烙铁（仅第 7、8 步各 1 处）、小十字螺丝刀、万用表、电脑。
> 总用时：**约 2.5 小时**（熟练 1.5 小时）。

| 阶段 | 内容 | 时间 |
|---|---|---|
| A | 桌面准备 + 认针脚 | 15 min |
| B | 传感器插接 | 30 min |
| C | 显示与执行器 | 30 min |
| D | 两个小电路（风扇驱动 / 电平转换） | 40 min |
| E | 装软件、上传固件 | 20 min |
| F | Duo 侧 + 联调 + 验收 | 25 min |

---

## 铁律（先读这三条，能省你两小时）

1. **插拔任何线之前先拔 USB / 断电。** 带电插拔最易烧 RC522 和舵机。
2. **手不碰金属部分，只捏杜邦线塑料头。** 手指同时碰 5V 与 GND 会短路保护重启。
3. **每完成一步就通一次电看一次结果**，别全接完再排错——全接完出错有 30 种可能，分步只有 1 种。

---

## A 阶段 · 桌面准备与认针脚

### 步骤 1｜摆好桌面（3 分钟）

【做】亚克力底板放平；UNO 竖向摆中间；面包板横放左侧；传感器按"左前右后"分类摆开。
【你会看到】桌面能一眼看到所有模块，不叠压。
【卡住】地方不够时，把 LCD1602 和 OLED 先收进袋子，C 阶段再拿。

### 步骤 2｜认 UNO 的四排针脚（5 分钟）

【做】把 UNO 拿正（USB 口朝下），从左到右找：
- **上排**：D13 … D2（数字）
- **下排**：GND、GND、5V、3V3、A0 … A5
【你会看到】板子上印着丝印，`A0~A5` 是模拟输入，`D2~D13` 是数字口。
【卡住】丝印太小 ⇒ 手机拍照放大看，别靠猜。

> ⚠️ 本项目的 16 个引脚**已排满**，`D0/D1` 必须空着（它们是 USB 串口通信用的，一插就上传不了固件）。

### 步骤 3｜面包板电源轨（5 分钟）

【做】面包板上下各有一条红（+）、蓝（−）长槽。从 UNO 引两根线：
- `5V` → 面包板红线
- `GND` → 面包板蓝线
【你会看到】以后所有模块的 VCC 都插红线、GND 都插蓝线，不用每根都回 UNO。
【卡住】面包板电源轨中间是**断开的**（左半截和右半截不通），若模块插在右边，要在中间**跨一根短线**接通。

## B 阶段 · 传感器插接（每接一个，通电压一次）

### 步骤 4｜DHT11 温湿度 → D2

【做】模块三针：`+`→红线(`5V`)、`OUT`→UNO **D2**、`−`→蓝线(`GND`)。
【你会看到】LCD 显示温度、湿度各一个数（湿度 30~80 正常）。
【卡住】湿度显示 `nan` ⇒ 线没插到底；换一根线再试。

### 步骤 5｜DS18B20 测温 → D3

【做】三针同上，`DQ`→UNO **D3**。**认准模块版**（小板上有电阻），裸件三极管样子的必须先焊 4.7kΩ。
【你会看到】温度读数，与 DHT11 相差 <1.5℃。
【卡住】读数 `-127` ⇒ 没上拉电阻 / 线断；读数 `85` ⇒ 刚上电还没转换，等 1 秒。

### 步骤 6｜四路模拟 + PCF8591（I2C）

【做】先把 MQ-2、火焰、光敏、声音四块模块的 `AO` 分别接 **PCF8591 的 AIN0/AIN1/AIN2/AIN3**；再把 PCF8591 的 `SCL→A5`、`SDA→A4`、`VCC→5V`、`GND→蓝线`。
【你会看到】串口日志里出现 4 个 0~255 的原始值；MQ-2 刚上电数值会一直下降（预热），30 秒后稳定。
【卡住】全是 255 ⇒ 地址或通道错；先用 `i2cdetect` 在 Duo 上扫（应见 `0x48`）。MQ-2 用打火机放气（不点火）数值应明显上升。

### 步骤 7｜U 型光电 → A0、干簧管 → A1、触摸 → A2

【做】三个模块都只有 `+ / OUT / −` 三针，OUT 分别进 **A0 / A1 / A2**。
【你会看到】手挡光电 → 读数跳变；磁铁靠近干簧管 → 跳变；手指碰触摸片 → 跳变。
【卡住】光电一直不变 ⇒ 模块上有蓝色电位器，用螺丝刀慢慢转，直到指示灯随遮挡变化。

## C 阶段 · 显示与执行器

### 步骤 8｜LCD1602 + OLED（都接 I2C，可并联）

【做】两块板的 `VCC→5V`、`GND→蓝线`、`SDA→A4`、`SCL→A5`（与 PCF8591 共用同一对线，直接叠插）。
【你会看到】LCD 亮背光、OLED 点亮；若全黑，先调 LCD 背面电位器调对比度。
【卡住】LCD 花屏/白块 ⇒ 地址不对，把代码里 `0x27` 改 `0x3F` 试。

### 步骤 9｜有源蜂鸣器 → D4、7 色 LED → D5

【先判】**本项目必须用有源蜂鸣器**。套件里两种都有，外观几乎一样：模块 `VCC→5V`、`GND→GND`，`I/O` 直接碰 `5V`——**响的是有源，不响的是无源**（无源要 2–5 kHz 方波才响）。拿不准就烧 `04-物联网项目\buzzer_check\buzzer_check.ino`，串口会直接打印结论。
【做】**有源**蜂鸣器 `I/O→D4`、LED 模块 `S→D5`，电源照旧。
【你会看到】上电后蜂鸣器不响（正常）；上传固件后报警时会响。
【卡住】一直不响 ⇒ 多半装成了**无源**模块，换套件第 19 项有源模块；一直响 ⇒ 是低电平触发模块，代码里电平取反即可。

### 步骤 10｜继电器 → D6（先别接负载）

【做】`IN→D6`、`VCC→5V`、`GND→蓝线`。
【你会看到】上电瞬间"咔"一声（继电器吸合），板载 LED 亮 = **本项目要求的上电状态**。
【卡住】不吸合 ⇒ 多数模块是低电平触发，确认 `IN` 对的是 D6 而不是 5V。

### 步骤 11｜舵机 → D7（单独供电）

【做】橙线→**D7**；红线→**独立 5V/2A 电源正极**；棕线→**GND**（与 UNO 共地！）。
【你会看到】上电舵机不抖（若抖动=供电不足或没共地）。
【卡住】一刷卡 UNO 就重启 ⇒ 舵机还在从 UNO 5V 取电，改独立电源。

## D 阶段 · 两个小电路（唯一需要烙铁的地方）

### 步骤 12｜风扇驱动（S8050 + 1kΩ + 1N4007）

```
   独立5V(+) ──┬──────────── 风扇(+)
               │                │
               │            风扇(−)
               │                │
   D9 ──1kΩ── b               c
             S8050            │
               e ── GND ──────┘

   1N4007 反并：阳极接风扇(−)，阴极接风扇(+)   ← 防关机反电动势
```

【做】按图在面包板搭：1kΩ 一端接 D9、另一端接 S8050 的 `b`；`e` 接 GND；`c` 接风扇负极；风扇正极接独立 5V。最后把 1N4007 **反向**并在风扇两端（银圈那端朝 +）。
【你会看到】D9 输出高电平时风扇转，低电平停。
【卡住】风扇不转 ⇒ ①三极管方向插反（看平面对着自己，左到右 `e b c`）②1N4007 接反（会短路，立刻断电重接）。

### 步骤 13｜RC522 供电与电平转换

【做】RC522 **只接 3.3V**：`3.3V`、`GND`、`SDA→D10`、`SCK→D13`、`MOSI→D11`、`MISO→D12`、`RST→3.3V`。
【你会看到】模块上的小灯常亮；拿卡靠近，串口打印卡号。
【卡住】不读卡 ⇒ ①先量 VCC 是否 3.3V（接 5V 会烧）②买到的是裸 3.3V 版就必须加 **BSS138 四路电平转换板**在 UNO 与 RC522 之间，否则通信不稳。

### 步骤 14｜第一次全系统上电（先别接风扇与舵机）

【做】只插 UNO 的 USB，观察 30 秒。
【你会看到】LCD 有数据、OLED 有数据、继电器吸合、无异常发热。
【卡住】UNO 反复重启 ⇒ 立刻断电，检查是否有 5V 与 GND 直连（短路），重点查面包板电源轨。

## E 阶段 · 软件与固件

### 步骤 15｜装 Arduino IDE 2.x 与 6 个库

【做】IDE → 库管理器，按**这个版本**装（版本错是最常见的编译失败原因）：

| 库 | 版本要求 | 备注 |
|---|---|---|
| DHT sensor library (Adafruit) | 1.4.x | 同时装 Adafruit Unified Sensor |
| OneWire | 2.3.8 | |
| DallasTemperature | 3.9.x | |
| IRremote | **≥4.0** | 4.x 用 `IRremote.hpp` + `IrReceiver.begin()` |
| LiquidCrystal_I2C | **Frank de Brabander 1.1.4** | 用 `init()`，不是 `begin()` |
| U8g2 | 2.35.x | 用 HW_I2C 构造 |
| MFRC522 | 1.4.11 | |
| Servo | IDE 自带 | 独占 Timer1，故 D9 只能用 digitalWrite |

【你会看到】库管理器里版本号与上表一致。
【卡住】装了两个同名库（一个叫 LiquidCrystal_I2C 一个叫 NewLiquidCrystal）⇒ 删掉多余的，只留一个。

### 步骤 16｜上传固件

【做】打开 `UNO_Node\UNO_Node.ino` → 工具里选 `Arduino Uno` 和对应 COM 口 → 点上传。
【你会看到】"上传成功"，LCD 开始刷新数据。
【卡住】
- 报 `avrdude: port busy` ⇒ 关掉串口监视器再传。
- 报 `IRremote.h: No such file` ⇒ 库版本 <4.0，升级。
- 报 `'class LiquidCrystal_I2C' has no member named 'init'` ⇒ 换回 1.1.4。

### 步骤 17｜Duo 侧：联网 + 跑桥接

【做】① Duo 通电，网线接路由器，记下 IP；② 电脑 `ssh root@<Duo-IP>`；③ 装依赖 `pip3 install pyserial requests`；④ 把 `duo_bridge.py` 拷进去 `scp duo_bridge.py root@<IP>:/root/`；⑤ 改脚本里的 `PORT` 与后端地址；⑥ 运行 `python3 duo_bridge.py`。
【你会看到】终端每 2 秒打印一行 `@E,...`。
【卡住】`Permission denied: /dev/ttyUSB0` ⇒ 用 `ls -l /dev/ttyUSB*` 确认设备名，或 `chmod 666` 临时放开。

## F 阶段 · 联调与验收

### 步骤 18｜五项功能挨个点一遍

| # | 操作 | 应该发生 | 不对就查 |
|---|---|---|---|
| 1 | 正常静置 | 继电器吸合，风扇停，绿灯 | 继电器初值被改过 |
| 2 | 打火机放气（不点火） | 3s 内风扇转 + 长鸣 + 红灯，台面负载断电 | 阈值 120/200、MQ-2 预热 |
| 3 | 明火靠近 | 立即报警 | 火焰阈值 150/250 |
| 4 | 刷授权卡 | 舵机开锁 3s 回锁 | 卡号白名单 `CARDS` |
| 5 | 刷非法卡 | 两声短鸣，不开锁 | Duo 是否回 `@L,0` |

### 步骤 19｜拔电重上电，看是否自动恢复

【做】断电 10 秒再上电。
【你会看到】30 秒预热后自动回到正常，不需要手动按任何键。
【卡住】不恢复 ⇒ 检查 `setup()` 是否被改过。

### 步骤 20｜收尾固定

【做】扎带捆线、双面胶固定模块、贴上引脚标签纸。
【你会看到】桌面整洁，任意一根线都能顺着找到来源。

## 出问题先看这张表（90% 的坑都在这里）

| 现象 | 90% 的原因 | 一句话解决 |
|---|---|---|
| 上传不了 | D0/D1 被占用 | 拔掉 D0/D1 上的线 |
| LCD 全黑有背光 | 对比度电位器 | 拧背面蓝色电位器 |
| LCD 白块 | I2C 地址 | `0x27` 改 `0x3F` |
| OLED 不亮 | 构造宏选错 | 必须 `HW_I2C` |
| 读数全 0 / 全 255 | 地址或通道 | `i2cdetect` 确认 `0x48` |
| 舵机一动就重启 | 电源没分开 | 独立 5V + 共地 |
| 风扇不转 | 三极管/二极管方向 | 照图重认 `e b c` 与银圈 |
| 读不到卡 | 不是 3.3V | 量 VCC，接 5V 已烧 |
| 报警不响 | 蜂鸣器是有源/无源买错 | 本项目必须**有源** |
| 烧完没反应 | 面包板电源轨断开 | 中间跨一根短线 |

> 更细的 16 条排障见 [README-接线与排障.md](README-接线与排障.md)，接线全图见 [电路图.svg](电路图.svg)。
