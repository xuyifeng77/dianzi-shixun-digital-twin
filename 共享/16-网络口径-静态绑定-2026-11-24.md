## 一、截图事实（唯一新口径来源）

路由器 → 局域网设置 → **静态地址绑定**，界面原样四列：

| 名称 | MAC 地址 | IP 地址 | 自定义网关地址 |
|---|---|---|---|
| `milky-a` | `02:01:0a:00:00:0a` | `192.168.5.9` | `192.168.5.1` |
| `milky-b` | `02:01:0b:00:00:0b` | `192.168.5.10` | `192.168.5.1` |

三点注意：

1. **名称是 `milky-*`，不是 `milkv-*`**。m-i-l-k-y，y；板子型号才叫 Milk-V（m-i-l-k-v）。路由器里注册什么，hostname 就得是什么，字符差一个 `ssh milky-a` 就解析不到。
2. **绑定是"MAC → IP"**，绑定关系在路由器里，板内不写死静态 IP。这条与 `13` D-02 一致，别在 `/etc/network/interfaces` 里再压一层。
3. **网关 `.1` 与网段 `192.168.5.0/24` 没变**，只有节点号的落点变了。

## 二、现行口径（唯一写法）

| 角色 | hostname | MAC | IP | 网关 |
|---|---|---|---|---|
| A 板（Uno 主控侧 / 架构样板） | `milky-a` | `02:01:0a:00:00:0a` | **`192.168.5.9`** | `192.168.5.1` |
| B 板（视觉节点） | `milky-b` | `02:01:0b:00:00:0b` | **`192.168.5.10`** | `192.168.5.1` |
| C 板（扩展位，未上板） | `milky-c` | 上板后补 | `192.168.5.11`（顺延） | `192.168.5.1` |
| D 板（扩展位，未上板） | `milky-d` | 上板后补 | `192.168.5.12`（顺延） | `192.168.5.1` |
| PC 看板 / 协调层 | — | — | `192.168.5.20:8000`（`POST /ingest`） | `192.168.5.1` |

一句话记法：**A 九、B 十、C 十一、D 十二、PC 二十，网关一点一。**

## 三、新旧对照（旧值仅留作溯源，不要再抄进新文档）

| 项 | 11-23 及以前 | 11-24 现行 | 变动原因 |
|---|---|---|---|
| A 板 IP | `192.168.5.7` | **`192.168.5.9`** | 路由器实际绑定就是 `.9`；`.7` 从未被绑定过 |
| B 板 IP | `192.168.5.8` | **`192.168.5.10`** | 同上 |
| C / D 板 IP | `.9` / `.10` | `.11` / `.12` | `.9/.10` 已被 A/B 占用，扩展位只能往后顺延 |
| hostname | `nodeA` ~ `nodeD` | **`milky-a` ~ `milky-d`** | 路由器注册名即 `milky-a`；`nodeA` 一套从未在任何一块板上落地 |
| 更早的网段 | `192.168.1.101/.102`、`192.168.1.11/.12` | 废弃 | `A/06` 已加时效说明 |
| 网关 / 网段 | `192.168.5.1` / `/24` | 不变 | — |

> 为什么 C/D 是"顺延"而不是"跟 A/B 换"：`.9/.10` 是路由器里**已经生效**的绑定项，改它要动两台在跑的机器；`.11/.12` 是空位，动它零成本。工程上永远是"改空位，不改在跑的"。

## 五、复核命令（谁用谁跑）

**在 PC 上（Linux / macOS / Windows 均可）**

```bash
ping 192.168.5.9              # A 板
ping 192.168.5.10             # B 板
ssh root@192.168.5.9          # 默认密码见 B/09 节点手册
ssh root@192.168.5.10
ssh milky-a.local             # mDNS 兜底；不通就是板内 hostname 没改或 avahi 没起
```

**在板子上（两块都跑，结果应逐字对上本文 §二）**

```bash
hostname                      # 期望 milky-a / milky-b
ip link show eth0             # 期望 02:01:0a:00:00:0a / 02:01:0b:00:00:0b
ip -4 addr show eth0          # 期望 192.168.5.9/24 或 .10/24
ip route | grep default       # 期望 default via 192.168.5.1
```

**在仓库里（查有没有旧口径漏网）**

```bash
grep -rn --include=*.md -E '192\.168\.5\.(7|8)\b|node[ABCD]\b|milkv-[ab]\b' .
```

命中项只允许出现在"历史作废说明"段落里（`A/06`、`A/13` 溯源段、`共享/15`、本文 §三）。
