**填写规则（本版新增）**
1. `cpu_scope` **每一行都要填**（`all_cores` 或 `per_core`），拿不到写 `NA`，不许留空。
2. `run_id` 用完整格式 `YYYYMMDD-<arch>-n<N>-r<NN>`，`arch` 小写 `alpha/beta`，重复次数两位补零。
3. `lat_e2e_ms` 与 `lat_pipe_ms` **是两段不同的时间**，不得互相替代；`lat_pipe_ms` 默认只在 β 组测，α 组写 `NA` 并在备注写"α 无节点结论步骤"。
4. `bw_Bps = tx_bytes / duration_s`（不是固定除 60）；`duration_s` 与 60 s 偏差 >10% 必须在备注说明。
5. 不适用/未测一律 `NA` + 备注原因；**未测不得填 0**。

**计算规则（本版新增）**
- `truth_total = tp + fn`；`auto_total = tp + fp`；`miss = truth_total − auto_total = fn − fp`（**miss 是计数差值，不是漏检数**）
- `tp/fn/fp` 必须靠人次级匹配得出；没做逐人次匹配的组，三列写 `NA`、备注加 `#count_only`，报告里只能称"计数偏差"
- `mean_conf` 仅对 `tp` 求平均；全组无检出自写 `NA`（不是 0）
- `mean_conf_all` = 全部 10 人次平均，未检出按 0 计
