## 三、开工顺序

1. 读 [`11-D岗-数据与实验.md`](11-D岗-数据与实验.md) §三，把自己当受试者预演一遍实验二（12 组怎么排、真值谁记）。
2. 按 [`04-实验设计.md`](04-实验设计.md) 的口径把记录表搬到看板录入页，字段名与契约 3 **逐字一致**。
3. 看板先用 fake 数据跑通三页，**不要等 B**；等 B 的 JSON（契约 4）到了只换数据源。

## 四、数据纪律（违反一次，数据全部作废）

- 原始 CSV **只增不改**；清洗结果写 `data/clean/`，不覆盖原始文件。
- 缺失值统一 `NA`，不写 `0`、不写空。
- 每组实验开始前先写 `meta.json`（日期、架构 α/β、N、组别、操作人、固件与桥接版本号）。
- 名单与真值分开存放，报告里只出现编号。
