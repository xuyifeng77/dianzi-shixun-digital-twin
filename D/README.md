## 三、开工顺序

1. 先跑看板：`cd dashboard && python app.py --data ../data --port 8000` + 另一个窗口 `python mock_feed.py`，三页都看得懂再往下做（[`dashboard/README.md`](dashboard/README.md) §一）。
2. 读 [`契约3-签字页.md`](契约3-签字页.md) §二 8 条 —— 这 8 条就是别人填表时会问的全部问题；再用 [`04-实验设计.md`](04-实验设计.md) 的表格把字段名逐字核一遍。
3. D4 用 B 的 **样例 JSON**（不是设计稿）跑一遍 `/ingest`，写 `meta.json`；D5 契约 4 联调；**别等 B 的板子才动手**。

## 四、数据纪律（违反一次，数据全部作废）

- 数据根只有一个：`D/data/`。`raw/` **只增不改**；清洗结果写 `data/clean/`，不覆盖原始文件。
- 缺失值统一 `NA`，不写 `0`、不写空。
- 每组实验开始前先写 `meta.json`（日期、架构 α/β、N、组别、操作人、固件与桥接版本号）。
- 名单与真值分开存放，报告里只出现编号。
- 真值**整组只用一种来源**：默认 U 型光电；光电不可用整组改人工并标 `#manual_truth`，**同组不得混用**（契约 3 §3.1）。
