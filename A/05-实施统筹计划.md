## 1. 三个阻断性判断（先做，做完才能排期）

### 1.1 怎么连上板子（今天就能定）

底板在位 → USB-NCM 不可用 → 数据通道只剩两条：

| 通道 | 前提 | 优点 | 缺点 |
|---|---|---|---|
| **RJ45 网口** | 需要**带 DHCP 的路由器**（交换机单独不行，官方镜像 `eth0` 是 DHCP） | 拿到 IP 后一切照常，SSH 就能干活 | 校园网通常上不了；没有路由器就得买 |
| **串口四针** | 需 CH340（≈¥10，跳线选 **3.3V**） | 不依赖网络；能看到 boot 日志；救砖唯一手段 | 只能看日志，传文件慢 |

**建议**：两根都备。串口是"能看见真相"的通道，出问题时不至于面对一块黑盒子。

**SSH 口令**：`root` / `milkv`（以 02 §7 记录为准；若无密码则直接回车，比盲目重烧省事）。

### 1.2 UNO ↔ Duo 的 USB 链路通不通（30 分钟判决实验）

`B\duo_bridge.py` + `C\UNO_Node\UNO_Node.ino` 走的是 **UNO 插 Duo 的 USB-A**，由 Duo 当 host；而 `02-系统设计` 走的是 **UNO 接 PC**。**同一个 USB 口只能二选一**，两条路线不能同时成立。

- 底板在位时，Duo 的 USB 口天然是 host 角色，对 04 路线**有利**；
- 但需显式切换：`ln -sf /mnt/system/usb-host.sh /mnt/system/usb.sh` 后重启；
- 判决方法：切完插 UNO，看 `ls /dev/ttyUSB*`、`lsusb`、`dmesg | tail` 是否出现 `ch341`/`cdc_acm`；
- 失败退路（可行性报告 §4 已给）：底板四针直连，`UNO TX(5V) → 1k/2k 分压 → Duo RX`，`UNO RX ← Duo TX(3.3V)`。

**这个实验要在写任何节点程序之前做**，因为它决定 04 的架构成立与否，也决定 02 的"UNO 只接 PC"是否要改。

> **收数表**：要测哪 5 项、每项的命令与判据、拿到什么组合就判哪条路、2 小时止损怎么走 —— 全部在 [`14-判决输入清单-通信链路三选一.md`](14-判决输入清单-通信链路三选一.md)；测完把 §五 回填区摘成 `1.4 连板方式判决`。

### 1.3 256MB 改写了报告的核心论证 ⚠️

`02 §1.3` 用「Linux 只看到 28MB」论证协调层必须放 PC。**这个论据在 SG2002 上不成立**（可用约 200MB）。处理方式：

- **结论保留，理由替换**：PC 必须承担①实时看板与录像存储、②**实验对照组 α 的解码与全量推理**（公平性要求两种方案在 PC 上用同一算法）。这两条与内存无关，比原论据更硬。
- **补一句"未来工作"**：若后续换用更大内存型号或做模型瘦身，协调层可下沉，实现完全去中心化。
- **必须改**，否则答辩时被问"你的板子是 256M，为什么说只有 28MB"会直接失分。

同理，`02 §7` 的"固件必须 V1 系列""模型必须 `scrfd_320_256_ir_0x.cvimodel`（CV180X 专用）"是针对 CV1800B 的。**SG2002 需用对应型号的 TDL SDK 与 cvimodel**，具体文件名以官方 SDK 为准，不要照抄。

## 3. 决策闸门：实验到底要几块板

`02 §6.2` 设计的自变量是 **N ∈ {1,2,3,4} × α/β = 8 组**。**2 块板只能测 N=1,2，即 4 组。**

| 选择 | 代价 | 后果 |
|---|---|---|
| **A. 补 2 套**（Duo 256M + 摄像头 + 卡 + 电源，约 ¥400–600） | 钱 + 1 周到货 | 8 组实验完整，结论"随 N 放大"才站得住 |
| **B. 不补，改为 N∈{1,2}** | 0 | 只能画 2 个点；"线性增长 vs 几乎不变"的分叉不明显，**推论强度大幅下降** |
| **C. 折中**：2 块板跑 α/β 各 N=1,2，另用 PC 侧模拟 4 个节点发送**合成流量** | 0 | 带宽结论可补强，但 CPU/延迟结论不真实，须在报告中明确标注"模拟" |

**必须在阶段 5 之前决定**，因为它同时决定要不要再买卡、电源、摄像头。若补，**务必确认新增板卡同为 SG2002**（混装会导致镜像/模型全对不上）。

## 6. 风险与应对

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 校园网/宿舍网不给 DHCP | 上电后路由器客户端列表里没有 `milky-a` / `milky-b` | 自备路由器，或串口 + PC 静态 IP 直连 |
| UNO 插 Duo 的 USB-A 枚举失败 | `ls /dev/ttyUSB*` 为空 | 走底板四针串口（分压），协议不变 |
| musl 环境装不上需要的依赖 | `pip install` 报错或找不到 wheel | 能用 busybox/C 就不上 Python；必须 Python 时源码交叉编译 |
| 根分区 768MB 写满 | `df -h` 占用 >85% | 阶段 0 就扩分区，别等 |
| 多块板同时推理降频 | 延迟抖动、帧率下降 | 散热片 + 分开放置 + 控制实验时长 |
