## D4-01 通信链路：按止损落 **①（UNO 经 PC）**，③ 记"未验证"

| 项 | 内容 |
|---|---|
| 依据 | `A/05 §1.4.4` 预登记止损：**2026-11-26 18:00 前拿不到 T2/T3 → 正式路线落 ①，③ 记"未验证"**。到 11-26 20:53，T2 仍无（UNO 在 C 的 PC 上，`COM11`），T3 未做，T4/T1b 未回报 |
| 结论 | 正式路线 **①**：UNO ──USB──> PC ──网络──> 协调层（看板/鉴权）；③（UNO 插 Duo 的 USB-A host）**保留作"未验证"**，报告里如实写"受设备在位限制，未取得 host 枚举证据" |
| 代价（写进报告） | ① = **断网即失能**。β 的"边缘自足"只在视觉通路上成立，传感器/执行那条是折中——这一条必须主动讲，别等答辩被问 |
| 连带改动 | ① 契约 1 §1「链路」行 → C 改 **v1.2**、A 重签（帧格式不动）；② `A/03 §4.2` D0/D1 行、§9 已改；③ 契约 5 加"UNO 挂在哪"（v1.0a）；④ `duo_bridge.py` 默认端口改为 PC 宿主（`COM11`）；⑤ `D/04` 的"中心"= PC、"带宽"按 UNO→PC 段 + 网络段分开写 |
| 回补条件（唯一的翻案口） | 若 11-27 12:00 前补到 **T2 见 `ch341`/`ttyUSB0` + T3 切 host 后仍拿 IP + T4 ≥ 4.75 V 且 ≤ 450 mA**，按 `05 §1.4.3` 可改判 **③**（契约 1 再升 v1.3、A 重签一次）；只满足 T2 不满足 T4，则 ③ 只能"独立供电 + 只跑数据"，仍不算正式路线 |

## D4-02 7 色 LED：按"**只表有/无告警**"定稿，三级颜色降为"待实测增强项"

| 项 | 内容 |
|---|---|
| 依据 | 单脚 7 色模块没有独立三通道，PWM 只改亮度；C 未实测能否按档变色。`共享/07 §八` 已把这条列为"必须主动交代"的第 1 点 |
| 结论 | **报告与答辩按降级叙事写**：LED 只表"有/无告警"，三级语义（危险/注意/正常）由 LCD 的 `L` 字段 + 蜂鸣节奏（1000/1500 ms vs 150/3000 ms）表达，LED 亮度随等级变化**不作为主要证据** |
| 不改的东西 | 不换 RGB 三通道模块（A3 空闲是留给它的，但换模块要改固件 + 接线表 + 契约 2，D4 之后没这个预算） |
| 回补条件 | C 拍三张照片证明"30/120/240 三档真变色"→ 报告加一句"单脚模块经实测可区分三色"，**契约不用改**；拍不出就维持降级叙事，不再议 |
| 连带 | `C/LED方案决策.md §4` 由 A 填的判定结论 = 本条；`A/03 §5.3`、附 A P6 已同步 |

## D4-03 防尾随判定：钉在 **bridge（上层）**，固件不改

| 项 | 内容 |
|---|---|
| 依据 | 三路事实（`@R` 刷卡 / `@D` 门磁 / `@C` 人次）固件都已在发；固件只该"报事实 + 本地联锁"，判权在上层（`A/03 §5.1` 一贯口径）。bridge 已持有刷卡状态，改一处即可，改固件要重烧 + 改契约 1 |
| 结论 | 规则放 **B 的 bridge**：一次开锁窗口（`@L` 下发后 T = 3000 ms，取 `@L` 的实参）内 `@C` 人次 ≥ 2 → 打 `TAILGATE` 事件，不额外驱动蜂鸣（拒绝音已由固件负责） |
| 不改的东西 | 固件、契约 1 一律不动；`@C` 仍是累计人次，不新增帧 |
| 边界 | 窗口 T 与"≥2"是**初值**，实验三跑完按误报/漏报调（D 出统计口径，B 改桥接参数），**调参不改契约** |
| 连带 | `A/03 §5.1`、附 B 已同步；`D/04` 实验三按此口径写；`共享/17` 的 B-8/D-5 承接 |
