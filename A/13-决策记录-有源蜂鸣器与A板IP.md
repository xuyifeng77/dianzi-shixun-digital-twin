## D-01 声学输出：强制使用**有源**蜂鸣器（D4）

**决策**：D4 只接**有源蜂鸣器模块**（套件第 19 项）。无源模块（第 20 项）**不接**，退出核心件口径。

**为什么**

| 方案 | 驱动方式 | 代价 |
|---|---|---|
| **有源（采用）** | `digitalWrite(D4, HIGH)` 即响 | 只有单音，无音高变化 |
| 无源（弃用） | 需 2–5 kHz 方波，`tone()` | **`tone()` 占 Timer2，与 IRremote 的接收定时冲突**；v1 方案把无源放 A3 后正是因为这个才空置 |

分级语义改由**节奏编码**承担，固件已实现，不用改逻辑：

| 等级 | 响 | 停 | 周期 |
|---|---|---|---|
| 危险 L2 | 1000 ms | 500 ms | 1500 ms |
| 注意 L1 | 150 ms | 2850 ms | 3000 ms |
| 拒绝（非法卡） | 80 ms ×2 | — | 400 ms 内两声 |

**30 秒判定模块类型**（拆下来单独测，别接在整机上猜）

1. `VCC→5V`、`GND→GND`，`I/O` 直接碰 `5V`：**响 = 有源**；
2. 不响 → 把 `I/O` 接 UNO 的 D8，跑 `tone(8, 2700)`：**响 = 无源**；
3. 懒人版：烧 `C\buzzer_check\buzzer_check.ino`，串口直接打印结论。

**万一手上只有无源**

- 首选：换套件里的 19 号有源模块（同一套件两件都有，别去买）。
- 应急：`tone(PIN_BUZZ, 2700)` 能响，但必须同时放弃 IRremote（注释 `IrReceiver`）——**只许临时演示，不进冻结版**。

**判定后的动作**

- [ ] 模块丝印/背面看一眼有没有三极管与振荡电路（有源模块通常带）；拍照留证进 `标定记录.md`
- [ ] 上电不响、发 `@L,3000` 也不响 → 先量 D4 是否有 5 V 跳变，再怀疑模块
- [ ] 一直响 → 模块是低电平触发，代码电平取反或换模块（本项目按高电平响写）

## D-02 A 板固定 IP：`192.168.5.7`

**事实**：2026-11-23 实测，A 板接入现场路由后在 `192.168.5.0/24` 网段稳定取得 `192.168.5.7`。

**决策**：全项目网络口径统一到 `192.168.5.x`；**A 板 = `192.168.5.7`**，作为唯一写法。

| 设备 | 地址 | 状态 |
|---|---|---|
| Duo-A（`duo-a` / `nodeA`） | **192.168.5.7** | **已实测稳定（本决策依据）** |
| Duo-B（`duo-b` / `nodeB`） | 192.168.5.8 | 待按 MAC 绑定后回填 |
| Duo-C / D（扩展位） | 192.168.5.9 / .10 | 未上机 |
| PC（看板 / `SERVER`） | 192.168.5.20 | 现场核对后回填 |
| 网关 | 192.168.5.1 | 现场路由 |

**为什么改**：旧文档同时存在 `192.168.1.101/.102`（`02`）与 `192.168.1.11/.12`（`07`、`09`）两套互相矛盾的写法，且都不对应现场网段——`06` 已把"IP 口径不一致"列为文档缺陷。以实测值为准，一次改齐。

**做法**（保持"路由器按 MAC 绑定"而不是板上写死）

```sh
ip a show eth0            # 期望 inet 192.168.5.7/24
ping -c3 192.168.5.1      # 网关通
ssh root@192.168.5.7      # 密码 milkv
```

- 路由器后台：DHCP 客户端列表里按 A 板 MAC（`02:01:0A:00:00:0A`）绑定 `192.168.5.7`；
- 若现场路由网段会变（换场地/换热点），**以 A 板实际地址为准改这张表**，不要反过来去改板子；
- `duo_bridge.py` 的 `SERVER` 指向 PC：`http://192.168.5.20:8000/ingest`（PC 实际 IP 变了就改这一行）。

**验收**

- [ ] A 板断电重启 3 次，`ip a` 均为 `192.168.5.7`
- [ ] PC `ping 192.168.5.7` 通，`ssh` 秒进
- [ ] `duo_bridge.py` 能把 `@E` POST 到 `192.168.5.20:8000`（PC 起 `python -m http.server` 或看板服务验证）
