# 14 · 判决输入清单 · 通信链路三选一

> 用途：把 [`08 §五`](08-A岗-架构与协议.md) 的三个实验、[`05 §1`](05-实施统筹计划.md) 的"两条路线互斥"冲突，收成**一张能落笔的表**。
> 谁用：A 拍板时用这份收数据；B/C 照着 §三 的命令出数；D 按 §七 的口径改 CSV。
> 铁律：**判决必须写"实测数字 + 一句话理由"**，不接受"感觉能跑"。

---

## 一、判决只要回答三句话

1. UNO 的串口，**物理上**挂在谁身上？（Duo 的 USB-A / Duo 的底板四针 / PC）
2. 挂了之后，**Duo 还能不能上网**？（能上网才有 α 架构上报，断网就只能 ①）
3. 这条链路**带得动**吗？（USB-A 供电电压够不够、往返时延是多少）

答完这三句，契约 1（帧格式）一个字都不用改，改的只是接线与端口名。

---

## 二、三条路的事实对照（判决依据，不用测）

| | ③ Duo USB-A host | ② Duo 底板四针 UART | ① 经 PC 转 |
|---|---|---|---|
| 物理接线 | UNO 数据线插 IOB 的 USB-A；Duo 当 host | 底板四针（3V3/RX/TX/GND）↔ UNO 的 D2/D3，**必须 1k/2k 分压** | UNO 插 PC，PC 再走网络到 Duo |
| 前提条件 | IOB 在位 + `usb-host.sh` 切换成功 + **不抢 OTG 网络** | 40 针 pinmux 启用一路**非 console** UART + 分压电阻 | PC 常开、与板同网段 |
| 依赖谁 | B（切 host、看网络）＋ A（判） | C（分压接线）＋ B（pinmux） | 无人——最笨但最稳 |
| 失败表现 | `lsusb` 无设备 / 重启后 Duo 断网 | 电平不匹配，一发就乱码或打坏 IO | 断网即失能，不算边缘 |
| 边缘性 | ★★★ 节点自足 | ★★★ 节点自足 | ★ 依赖 PC 在场 |
| 协议影响 | 无（端口名 `ttyUSB0`/`ttyACM0`） | 无（同一套 ASCII `@` 帧） | 无（多一跳转发） |
| 判决后要写的契约 | 契约 5 节点表 | 契约 5 + 接线表（C 的契约 2） | α/β 口径里"中心"改成 PC |

**已有实测事实**（可直接用，不必重测）：本项目这块 UNO 是 **CH340 克隆板**，Windows 枚举 `USB-SERIAL CH340 (COM11)`、`VID_1A86&PID_7523`，Linux 下应出 `ttyUSB0`（走 `ch341`）。见 [`06 §P0-5`](06-项目审查报告.md)。

## 三、需要提供的东西（就这 5 项，按性价比排序）

> 每一项都写清"怎么取、取到什么就算数、影响哪个分支"。**命令在 Duo 上跑，输出原样贴到 §五。**

### T1 · 板子的物理配置（不用命令，看一眼就知道）★ 最重要

| 要回答 | 为什么决定判决 |
|---|---|
| 板子是否装着 **USB&Ethernet IO 底板**（`DUO_IOB_V1.11`） | 没装底板就没有 USB-A 口、也没有 RJ45 → **③ 直接出局**，只剩 ②/① |
| UNO 的板子型号（丝印/背面） | CH340 → `ttyUSB0`；16U2 → `ttyACM0`；换过板就要重测 |
| 底板四针串口丝印标的是什么（`3V3/RX/TX/GND`？还是 `RS232`？） | 是 TTL 3.3V 才好接；标 RS232 就得加电平转换，② 的成本上升 |

提供方式：**一句描述 + 一张底板照片**（拍 USB-A 口和四针那一侧）。

### T2 · host 模式枚举结果（实验 1）★ 决定 ③ 通不通

```bash
# ① 基线
lsusb ; ls /dev/ttyACM* /dev/ttyUSB* 2>/dev/null
# ② 切 host（若 /mnt/system/usb-host.sh 不存在，说明镜像不支持，直接记"不可用"）
ln -sf /mnt/system/usb-host.sh /mnt/system/usb.sh
sync ; reboot
# ③ 重启后插 UNO 数据线（必须是数据线），等 5 s
lsusb
ls /dev/ttyACM* /dev/ttyUSB* 2>/dev/null
dmesg | tail -30
```

**取到什么就算数**：`dmesg` 里出现 `ch341` 或 `cdc_acm` 的关键行 + 设备节点名。
**影响**：出现 `ttyUSB0`/`ttyACM0` → ③ 可行；什么都没有 → ③ 出局。

### T3 · 切完 host 之后 Duo 还能不能上网（实验 1 的后半段）★ 决定 ③ 能不能用

```bash
ip -4 addr show          # eth0 有没有 IP
ip route | head -3       # 有没有默认路由
ping -c 3 192.168.5.1    # 网关（以实际为准）
curl -s -m 3 -o /dev/null -w '%{http_code}\n' http://192.168.5.20:8000/ || echo NO_SERVER
```

**取到什么就算数**：`eth0` 有 IP 且能 ping 通网关。
**影响**：能上网 → ③ 成立（首选）；**断网** → ③ 降级为"答辩演示用"，正式实验走 ②（因为 α 架构必须自足上报）。

### T4 · USB-A 端口带载（实验 2）★ 决定 ③ 稳不稳

需要一只 **USB 电压电流表**（¥15 那种就行），串在 UNO 前面，记三种状态的电压/电流：

| 状态 | 电流 | 5V 电压 |
|---|---|---|
| 待机（UNO + LCD + 传感器静态） | ___ mA | ___ V |
| MQ-2 满加热 + 继电器吸合 | ___ mA | ___ V |
| 再叠风扇 + 舵机堵转（最坏） | ___ mA | ___ V |

**判据**：任何状态 **≥ 4.75 V** 才合格；低于就单独给 UNO 供 5V，**不让 Duo 供电**（数字乱跳、随机复位都从这儿来）。
没有电流表时：**用"跑 10 分钟看是否复位/花屏"替代**，并在记录里注明"无表，定性判定"。

### T5 · 链路往返时延（实验 3）★ 报告要用，不决定选路

设备名确定后在 Duo 上跑（把 `ttyUSB0` 换成实际名字）：

```bash
python3 - <<'EOF'
import serial, time
s = serial.Serial('/dev/ttyUSB0', 115200, timeout=1)
ts=[]
for _ in range(20):
    t0=time.time(); s.write(b'@Q\n')
    while time.time()-t0 < 1:
        if s.readline().startswith(b'@'): break
    ts.append((time.time()-t0)*1000)
ts.sort(); print('min %.1f  median %.1f  max %.1f ms' % (ts[0], ts[len(ts)//2], ts[-1]))
EOF
```

**取到什么就算数**：中位数一行。**影响**：报告写"链路 X ms + 推理 Y ms + 执行 Z ms"。

### 可选 T6 · ② 的可行性（只有 ③ 出局时才需要）

```bash
ls /mnt/system/ | head -50          # 有没有 pinmux 工具
duo-pinmux -l 2>/dev/null | head   # 列出可用 pinmux（若存在）
ls /dev/ttyS*                       # 启用后应多出一个 ttyS
```
外加：**手上有没有 1k/2k 电阻**（分压用，缺了 ② 当天做不成）。

## 四、结论树（拿到 T1–T4 就能自动落地）

| 观测组合 | 判决 | 理由一句话 |
|---|---|---|
| T1 有底板 + T2 出 `ttyUSB0`/`ttyACM0` + T3 能上网 + T4 ≥4.75 V | **③ 采用** | 插上就能跑，节点自足，协议零改动 |
| T2 出设备 + T3 **断网** | **③ 仅答辩演示**，正式实验走 **②** | α 架构要求节点自己上报，断网就不成立 |
| T2 出设备 + T4 **<4.75 V** | **③ 接线保留，UNO 独立供电**（仍算 ③） | 掉压是供电问题，不是链路问题 |
| T2 什么都枚举不到 | **② 底板四针 UART + 1k/2k 分压** | 协议不变，只换接线；2 h 内必须切换 |
| T1 没装底板 | **② （若四针可用）否则 ①** | 没有 USB-A 就没 ③ 这个选项 |
| T1 四针是 RS232 电平且缺转换器 | **① 经 PC** | 电平不匹配不能硬接，会打坏 IO |

**止损**：判决实验总时间盒 **2 小时**。2 小时拿不到 T2 的结论，直接按 ② 走，把 ③ 记为"未验证"——**不要在 host 模式上恋战**（[`09 §九`](../B/09-B岗-视觉节点.md) 也写了这条）。
